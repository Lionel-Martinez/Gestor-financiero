# Gestor Financiero

App móvil (Android/iOS) para gestionar dos espacios económicos independientes —Personal y LM Studio— con contabilidad de doble partida, funcionamiento offline completo y sincronización con un backend Laravel.

- `mobile/` — Ionic Vue + Capacitor + SQLite local. `npm install && npm test && npm run build`.
- `backend/` — Laravel API + MySQL 8.4. Ver `backend/README.md`.
- `docs/` — vault de Obsidian; empezar por `docs/00-Tablero-de-Control.md`.

**Estado:** núcleo de la V1. Ver el tablero para lo verificado y lo que falta.
